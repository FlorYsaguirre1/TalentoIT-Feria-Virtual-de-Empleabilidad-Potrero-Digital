# 🚀 TalentoIT - Feria Virtual de Empleabilidad
### Potrero Digital

Plataforma web de feria virtual de empleabilidad desarrollada en el marco del programa **Potrero Digital**, orientada a conectar talentos del sector IT con oportunidades laborales.

---

## 📁 Estructura del proyecto

```
TalentoIT-Feria-Virtual-de-Empleabilidad-Potrero-Digital/
├── index.html          # Página principal
├── assets/
│   ├── css/
│   │   └── styles.css  # Estilos globales
│   ├── js/
│   │   └── main.js     # Lógica principal
│   └── img/            # Imágenes y recursos visuales
├── src/                # Componentes y páginas adicionales
├── docs/               # Documentación del proyecto
└── README.md
```

---

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 🚀 Cómo correr el proyecto localmente

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/FlorYsaguirre1/TalentoIT-Feria-Virtual-de-Empleabilidad-Potrero-Digital.git
   ```
2. Abrí `index.html` en tu navegador.
